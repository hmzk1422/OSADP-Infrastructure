S3B. outcome/outcomes.py (NEW - live regression -> metalabel -> barrier pipeline)
fit_state_linregs(frame, targets, latent, train_mask, *, feature_columns, min_state_rows,
  ridge, purge_rows) -- hoisted from example_sequence linreg loop (strategy.py:496-528).
  One multi-output OLS per non-null latent state on future_return__* (t+1..t+n), run on the
  gp_feat* frame. Under-supported states stay NaN. Returns (predictions, report).
  This is the "regression based on GP".
predict_excursions(predictions, side) -- hoisted from strategy.py:534-543. Side-adjusts
  t+1..t+n predictions -> row-wise max/min = predicted_mfe/predicted_mae, i.e.
  regression-implied TP/SL widths. Pure function, no fitting.
fit_metalabel_tree(frame, predictions, excursions, labels, latent, ...) -- NEW.
  Tree-as-metalabeler. Inputs = linreg predictions PLUS linreg errors (predicted minus
  realized per horizon) plus gp_feat*/base features. Output = per-row take_probability /
  take_flag: whether the regression can be trusted here. Objective is expectancy, not
  hit-rate. Returns fitted tree + importances + OOS expectancy report.
build_predicted_barriers(frame, excursions, metalabel, barrier_cfg) -- NEW thin wrapper.
  Calls existing build_triple_barrier_sequence(mode="predicted") with predicted MFE/MAE
  as PT/SL, excluding take_flag==False rows first. triple_barrier.py untouched.
run_outcomes(model_frame, targets, cfg) -- NEW entry point composing the four above.
  Owns the outcome.model settings section. Returns OutcomeResult(predictions, excursions,
  metalabel, events, report).
