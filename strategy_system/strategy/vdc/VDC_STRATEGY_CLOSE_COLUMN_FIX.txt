  -> ValueError: missing price column: close

2. ROOT CAUSE (two bugs, one crash + one latent)
------------------------------------------------
Bug A (the crash): `build_state` hardcoded price_column="close", but the
`__main__` path feeds it `load_L2()` tick data, whose columns are:
  timestamp, event_type, best_bid_price, best_ask_price, bid/ask depth
  levels 2-20, agg_trade_id, price, quantity, ...
There is NO "close" column in L2 data. "close" only exists on:
  - L1 OHLCV candles (get_ohlcv -> open/high/low/close/volume), or
  - walk-forward windows in vdc_stresstest.py:746 (which correctly passes
    price_column="close" because ITS input is OHLCV).
The stale comment `# Matches df_path["price"]` even admitted the value
should have been price-like, not "close". Every other VDC entry point
agrees: run_vdc_strategy default is "mid_price", monte-carlo passes
"price" (stresstest.py:191), tests pass ["mid_price"] (vdc_test.py:1293).

Bug B (latent, would crash next): even with the right column,
vdc_leveraged_fund requires a DatetimeIndex OR timestamp_column
(lines 55-72). load_L2 returns a RangeIndex with "timestamp" as a plain
tz-naive column (verified: index=RangeIndex, ts dtype=datetime64[ns],
tz=None). Without timestamp_column it raises
TypeError: df must have a DatetimeIndex or provide timestamp_column.

3. THE FIX (strategy.py build_state, ~10 lines)
-----------------------------------------------
a) Before the run_vdc_strategy call, build the VDC price series from the
   book (guarded so OHLCV frames pass through untouched):
     df = df.copy()
     if "mid_price" not in df.columns and
            {"best_bid_price","best_ask_price"} <= set(df.columns):
         df["mid_price"] = (df["best_bid_price"]+df["best_ask_price"])/2.0
     if "mid_price" in df.columns and "price" in df.columns:
         df["mid_price"] = df["mid_price"].fillna(df["price"])
   Mid-price chosen because it is the VDC default (vdc_runner.py:19),
   defined on every book row (trade `price` is NaN on ~36k/82k quote-only
   rows), and matches what vdc/features.py:126 already computes.

b) Call-site changes:
     price_column="close"  ->  price_column="mid_price"
     + timestamp_column="timestamp" if "timestamp" in df.columns else None
   (the fund builder then sets a UTC DatetimeIndex from the column).
