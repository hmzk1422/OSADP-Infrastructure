VDC PORTFOLIO - DYNAMIC EXPOSURE RESIZER IMPLEMENTATION PLAN
Target file:
  strategy_system/strategy/vdc/policies/vdc_portfolio.py

1. OBJECTIVE
Replace the binary stop-loss kill switch with continuous exposure scaling.

Old behavior to remove:
  - stop_loss(...) returning True/1.0/0.0 or per-asset factors in [0, 1].
  - Once a portfolio drawdown trigger was reached, target weights were
    multiplied by zero indefinitely, with no re-risking path.

New behavior:
  - Maintain an exposure scalar S in [S_min, 1].
  - Compute the current bar's portfolio return using prior-bar S.
  - Update NAV, peak NAV, and drawdown.
  - Recompute S from the new drawdown.
  - Apply the new S to the following bar.
  - Never renormalize cross-sectional asset weights in response to S.

2. CORE FORMULAS
Let:
  w[i,t-1] = relative asset weight selected for bar t.
  R[i,t]   = asset return on bar t.
  S[t-1]   = exposure scale selected at bar t-1.
  R_cash   = cash return.

Raw strategy return:
  raw_gross_return[t] = sum(w[i,t-1] * R[i,t])

Effective portfolio return:
  effective_return[t] =
      S[t-1] * raw_gross_return[t]
      + (1 - S[t-1]) * R_cash

Default R_cash is 0.0.

Exposure schedule:
  S(DD) = 1.0 when DD >= soft_threshold.
  S(DD) = S_min when DD <= hard_threshold.
  Otherwise linearly interpolate between hard and soft thresholds.

Drawdown is a fraction, so:
  soft_threshold = -0.03 means 3% drawdown.
  hard_threshold = -0.10 means 10% drawdown.

3. NEW HELPER
Add after _apply_stop_loss:

  def compute_position_scale(
      drawdown,
      *,
      soft_threshold=-0.03,
      hard_threshold=-0.10,
      minimum_scale=0.0,
  ):
      Validate that:
        - drawdown is finite.
        - both thresholds are finite.
        - hard_threshold < soft_threshold <= 0.
        - minimum_scale is finite and in [0, 1].
      Return:
        - 1.0 when drawdown >= soft_threshold.
        - minimum_scale when drawdown <= hard_threshold.
        - linearly interpolated scale otherwise.
      Clip the final result to [minimum_scale, 1.0].

This helper must remain pure: no DataFrame, NAV, or global-state access.
