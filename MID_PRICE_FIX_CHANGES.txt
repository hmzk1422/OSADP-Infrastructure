    def _repair_one_file(df) -> pd.DataFrame:
        # 1. keep book ONLY on LOB rows; mask TRADE/BOOKDEPTH book -> NaN
        #    (this discards the STALE book_state the merger wrote there)
        # 2. ffill last LIVE quote onto later rows (causal, no lookahead);
        #    bfill only covers a file that OPENS with TRADE rows (same-hour
        #    LOB arrives ms later)
        # 3. trade execution price stays strictly in separate `price` column
        # 4. precompute mid_price = ((best_bid+best_ask)/2).round(2)
        #    .round(2) kills IEEE dust, e.g. 108613.20000000001 -> 108613.2
        #    downstream strategy.py:183-186 / features.py:126 reuse it via
        #    their `if "mid_price" not in df.columns` guard (read-only files)

(b) Rewrote load_L2() body (was: single concat + normalize + sort):
    BEFORE:
        df = pd.concat((read_parquet(f) for f in files))
        df = normalize_merged_frame(df)
        df.sort_values([timestamp, agg_trade_id])
    AFTER:
        per-file loop:
            one = normalize_merged_frame(read_parquet(file))
            sort by [timestamp, event_sequence] (was agg_trade_id;
                    event_sequence is the true causal key)
            frames.append(_repair_one_file(one))
        df = concat(frames).sort_values([timestamp, event_sequence])

    Why per-file: each hourly parquet's TRADE rows carry that hour's stale
    book; masking+ffill inside each file scope stops hour N's stale book
    leaking into hour M across the concat boundary.
